    打字试音

      怎么连

      • 设备和主机要在同一 Wi‑Fi / 同一网段（或 Tailscale）。不要做公网端口转发。
      • 主机先运行 bash scripts/run_server.sh。
      • 地址填主机局域网 IP，例如 ws://10.101.67.111:8765。不要填 127.0.0.1（那是这台设备自己），也不要填 198.18.x（Clash 假 IP）。
      • 换一台 Linux：拷这份程序，只改上面的主机 IP。
